Topic Strings

  • Operations on strings.

    String literals are enclosed in double quotes and support the escape sequences \n, \t, \r, \b, \" and \\.

    Strings are concatenated with + and repeated with *. Many string operations work by converting a string into a list of single-character strings with chars.

    • Function Detail

      • sprint

        (sprint <expressions...>)

        Converts one or more values to strings and concatenates them.

        Kind:
        Implemented natively by the interpreter.
        Returns:
        string
        Example:
        (let my_list (list 1 2 3 4))
(let my_number 21)
(sprint "my_list = " my_list ", my_number = " my_number)
# "my_list = (1 2 3 4), my_number = 21"

      • chars

        (chars <string>)

        Splits a string into a list of single-character strings.

        Kind:
        Implemented natively by the interpreter.
        Returns:
        string list
        Throws:
        EvaluationError - if the argument is not a string
        Example:
        (chars "Hello") # ("H" "e" "l" "l" "o")

      • strlen

        (strlen <string>)

        Returns the length of a string in bytes.

        Kind:
        Implemented in Nomad Lisp as part of the prelude.
        Returns:
        number
        Example:
        (strlen "Hello") # 5

      • splitws

        (splitws <string>)

        Splits a string on spaces, discarding empty parts.

        Kind:
        Implemented natively by the interpreter.
        Returns:
        string list
        Throws:
        EvaluationError - if the argument is not a string
        Example:
        (splitws "  Nomad   Lisp  is   Written in    OCaml!   ")
# ("Nomad" "Lisp" "is" "Written" "in" "OCaml!")

      • trim

        (trim <string>)

        Removes leading and trailing whitespace from a string.

        Kind:
        Implemented natively by the interpreter.
        Returns:
        string
        Throws:
        EvaluationError - if the argument is not a string
        Example:
        (trim "    Hello   World!   ") # "Hello   World!"

      • lower

        (lower <string>)

        Converts the ASCII letters of a string to lowercase.

        Kind:
        Implemented natively by the interpreter.
        Returns:
        string
        Throws:
        EvaluationError - if the argument is not a string
        Example:
        (lower "HELLO WORLD!") # "hello world!"

      • has_prefix

        (has_prefix <string> <prefix>)

        Tests whether a string begins with another string.

        Kind:
        Implemented in Nomad Lisp as part of the prelude.
        Returns:
        bool
        Example:
        (has_prefix "Hello World!" "Hello") # true

      • has_suffix

        (has_suffix <string> <suffix>)

        Tests whether a string ends with another string.

        Kind:
        Implemented in Nomad Lisp as part of the prelude.
        Returns:
        bool
        Example:
        (has_suffix "Hello World!" "World!") # true
