Topic Variables

  • Binding, mutating and scoping variables.

    Bindings are introduced with let and live in the scope they were created in. A binding may shadow a binding of the same name in an outer scope, but it may not be redeclared within the same scope.

    Bindings are immutable by convention. Mutation is always explicit and is performed with mut.

    Note that let is not the let of traditional Lisps. The construct that introduces a lexical scope is called scoped in Nomad Lisp.

    • Function Detail

      • let

        (let <name> <expression>)

        Binds the value of an expression to a name in the current scope.

        The expression is evaluated eagerly before it is bound. Shadowing a binding from an outer scope is permitted.

        Kind:
        Implemented natively by the interpreter.
        Parameters:
        name - a symbol naming the binding
        expression - the expression whose value is bound
        Returns:
        unit
        Throws:
        EvaluationError - if a binding with the same name already exists in the current scope
        Example:
        (let x 10)
(let y 20)
(println (+ x y)) # 30

      • mut

        (mut <name> <expression>)

        Replaces the value of an existing binding.

        The innermost binding with the given name is mutated. The binding may live in the current scope or in any enclosing scope.

        Kind:
        Implemented natively by the interpreter.
        Parameters:
        name - a symbol naming an existing binding
        expression - the new value
        Returns:
        unit
        Throws:
        EvaluationError - if no binding with that name exists in the current or any outer scope
        Example:
        (let counter 0)
(mut counter (inc counter))
(println counter) # 1

      • scoped

        (scoped ((<name> <expression>)...) <body>)

        Evaluates an expression within a new lexical scope.

        Optionally introduces scope-exclusive bindings. All binding expressions are evaluated in the enclosing scope before any of them are bound. The bindings cease to exist once body has been evaluated.

        Kind:
        Implemented natively by the interpreter.
        Parameters:
        bindings - a list of (name expression) pairs, possibly empty
        body - the expression to evaluate in the new scope
        Returns:
        the value of body
        Throws:
        EvaluationError - if the binding list is malformed
        Example:
        (scoped
  ((x 10)
   (y 20))
  (+ x y)) # 30
# x and y do not exist here anymore

      • args

        args

        The command-line arguments passed to the interpreter.

        args is a predefined global binding, not a function. When a script is run, the first element is the path of the script itself, followed by any further arguments.

        Kind:
        A predefined binding.
        Returns:
        string list
        Example:
        # nomad greet.nomad Alice
(println "Hello, " (car (cdr args))) # Hello, Alice
