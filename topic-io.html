Topic Input/Output

  • Console, file and directory I/O.

    Functions for reading from standard input, writing to standard output, and working with files and directories. All file system functions throw if the operating system reports an error.

    • Function Detail

      • print

        (print <expressions...>)

        Prints one or more values to standard output.

        Kind:
        Implemented natively by the interpreter.
        Returns:
        unit
        Example:
        (print "x = " 42)

      • println

        (println <expressions...>)

        Like print, followed by a newline.

        Kind:
        Implemented natively by the interpreter.
        Returns:
        unit
        Example:
        (println "Hello, " "World!")

      • readln

        (readln <prompt: string>)

        Prints a prompt and reads a line from standard input.

        The trailing newline is not included in the result.

        Kind:
        Implemented natively by the interpreter.
        Returns:
        string
        Throws:
        EvaluationError - if the prompt is not a string, or if the end of input has been reached
        Example:
        (println (+ "Hello, " (readln "Enter your name: ")))

      • read_file

        (read_file <path: string>)

        Reads the entire contents of a file.

        Kind:
        Implemented natively by the interpreter.
        Returns:
        string
        Throws:
        EvaluationError - if the file does not exist, is a directory, or cannot be read

      • write_file

        (write_file <path: string> <content: string>)

        Writes a string to a file, replacing its contents.

        The file is created if it does not exist.

        Kind:
        Implemented natively by the interpreter.
        Returns:
        unit
        Throws:
        EvaluationError - if the parent directory does not exist, or the file cannot be written

      • remove_file

        (remove_file <path: string>)

        Deletes a file.

        Kind:
        Implemented natively by the interpreter.
        Returns:
        unit
        Throws:
        EvaluationError - if the file does not exist or cannot be removed

      • read_dir

        (read_dir <path: string>)

        Returns the names of the entries in a directory.

        Kind:
        Implemented natively by the interpreter.
        Returns:
        string list
        Throws:
        EvaluationError - if the directory does not exist, is a file, or cannot be read

      • mkdir

        (mkdir <path: string>)

        Creates a directory.

        Kind:
        Implemented natively by the interpreter.
        Returns:
        unit
        Throws:
        EvaluationError - if the parent directory does not exist, or the directory cannot be created

      • remove_dir

        (remove_dir <path: string>)

        Removes an empty directory.

        Kind:
        Implemented natively by the interpreter.
        Returns:
        unit
        Throws:
        EvaluationError - if the directory does not exist, is not empty, or cannot be removed
