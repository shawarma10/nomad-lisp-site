Topic Control Flow

  • Sequencing, branching and exception handling.

    Nomad Lisp is expression-oriented: every construct evaluates to a value, including if and switch. Constructs that would be special syntax in other languages are ordinary functions that receive their arguments unevaluated.

    Errors are handled with an exception-based model using try and throw.

    • Function Detail

      • if

        (if <cond> <yes> <no>)

        Evaluates one of two expressions depending on a condition.

        If cond evaluates to true, yes is evaluated; if it evaluates to false, no is evaluated. The branch that is not taken is never evaluated.

        Kind:
        Implemented natively by the interpreter.
        Returns:
        the value of the evaluated branch
        Throws:
        EvaluationError - if cond does not evaluate to a bool
        Example:
        (println
  (if (> 3 2)
    "True!"
    "False!")) # True!

      • unless

        (unless <cond> <then> <else>)

        The inverse of if.

        Evaluates then if cond is false, and else otherwise. Expands to (if (not cond) then else).

        Kind:
        A macro defined in the prelude.
        Returns:
        the value of the evaluated branch
        Example:
        (unless false
  (println "I will be printed!")
  (println "I will not be printed!"))

      • when

        (when <cond> <body>)

        Evaluates an expression only if a condition holds.

        Like if without the second branch; intended for imperative control flow. Expands to (if cond body unit).

        Kind:
        A macro defined in the prelude.
        Returns:
        the value of body, or unit
        Example:
        (when (= 1 1) (println "Always printed"))

      • switch

        (switch <scrutinee> (<matcher> <expression>)...)

        Selects an arm by comparing a value against several matchers.

        Comparable to switch in C# or Java. The scrutinee is evaluated once; then each arm's matcher is evaluated in order and compared to it using the semantics of =. The expression of the first matching arm is evaluated.

        Matchers may be arbitrary expressions. The special matcher _ matches unconditionally and therefore acts as the default case.

        Kind:
        Implemented natively by the interpreter.
        Returns:
        the value of the matching arm, or unit if no arm matched
        Throws:
        EvaluationError - if an arm is not of the form (matcher expression)
        Example:
        (let scrutinee 100)
(switch scrutinee
  (10 (println "This is 10!"))
  (50 (println "This is 50!"))
  (100 (println "This is 100!"))
  (_ (println "This is neither 10, 50 or 100!")))

      • do

        (do <expressions...>)

        Evaluates several expressions in order.

        Constructs such as if or letfun accept a single expression for each body or branch. do groups several expressions into one. Evaluation stops at the first exception.

        Kind:
        Implemented natively by the interpreter.
        Returns:
        the value of the last expression, or unit if none were given
        Example:
        (println
  (do
    "I will be ignored"
    "I will be ignored as well"
    "I will be printed"))

      • try

        (try <expression> <on-error>)

        Evaluates an expression and recovers from any exception it throws.

        If evaluating expression throws, the exception is discarded and on-error is evaluated instead.

        Kind:
        Implemented natively by the interpreter.
        Returns:
        the value of expression, or the value of on-error if an exception was thrown
        Example:
        (let x "123abc")
(try
  (string_to_num x)
  (println "Couldn't parse " x " to a number!"))

      • throw

        (throw <message: string>)

        Throws an exception carrying a message.

        Kind:
        Implemented natively by the interpreter.
        Returns:
        never returns
        Throws:
        EvaluationError - always; additionally if message is not a string
        Example:
        (letfun expects_string (str)
  (if (isstr str)
    (println "All good!")
    (throw "The argument to this function must be a string!")))
