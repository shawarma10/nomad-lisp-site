    How This Documentation Is Organized

    This documentation has pages corresponding to the items in the navigation bar, described as follows.

    • Overview

      The Overview page is the front page of this documentation and lists all guides and topics, with a summary for each.

    • Guide

      Guides are prose documents that introduce the language, explain how to build and run the interpreter, and describe what an implementation of Nomad Lisp must provide.

    • Topic

      Each topic has a page that documents a group of related functions. Each topic page contains a description of the topic, a Function Summary table and detailed descriptions of each function. Each function entry lists:

      • Signature
      • Description
      • Kind (native, prelude or macro)
      • Parameters, return value and exceptions
      • An example, where appropriate

      The tabs above the Function Summary table filter the functions by kind.

    • Index

      The Index contains an alphabetic list of all functions, macros and predefined values.

    • Prev/Next

      These links take you to the previous or next topic.

    • Frames/No Frames

      These links show and hide the navigation panes on the left. Your choice is remembered across pages.

    This help file applies to the documentation of the Nomad Lisp standard library.
