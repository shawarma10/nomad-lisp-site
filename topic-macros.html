Topic Macros

  • Defining syntactic templates.

    The macro system of Nomad Lisp is deliberately small. A macro is a template: when it is invoked, every occurrence of a parameter name in the template is replaced by the corresponding unevaluated argument, including occurrences nested inside lists. The resulting expression is then evaluated in the caller's scope.

    For example, the invocation

    (unless false
  (println "I will be printed!")
  (println "I will not be printed!"))

    of the macro (letmac unless (cond yes no) if cond no yes) expands into

    (if false
  (println "I will not be printed!")
  (println "I will be printed!"))

    The prelude defines the macros unless, when and !=.

      • letmac

        (letmac <name> (<parameters...>) <template...>)

        Defines a macro in the current scope.

        The template consists of all remaining expressions, which together form the expression the macro expands to. Macros are invoked with exactly as many arguments as they have parameters.

        Kind:
        Implemented natively by the interpreter.
        Returns:
        unit
        Throws:
        EvaluationError - if the name is already bound in the current scope, if the parameter list contains a non-symbol, or, on invocation, if the wrong amount of arguments is given
        Example:
        (letmac when (cond body) if cond body unit)
(when true (println "I will always be printed!"))
