    Symbols

    != - Macro in topic Conditionals
    The inverse of =.
    * - Native function in topic Arithmetic
    Multiplies two numbers, or repeats a string.
    + - Native function in topic Arithmetic
    Adds two numbers or concatenates two strings.
    - - Native function in topic Arithmetic
    Subtracts rhs from lhs.
    . - Native function in topic Records
    Returns the value of a record field.
    / - Native function in topic Arithmetic
    Divides lhs by rhs.
    < - Native function in topic Conditionals
    Tests whether lhs is less than rhs.
    <= - Native function in topic Conditionals
    Tests whether lhs is less than or equal to rhs.
    = - Native function in topic Conditionals
    Tests two values for equality.
    > - Native function in topic Conditionals
    Tests whether lhs is greater than rhs.
    >= - Native function in topic Conditionals
    Tests whether lhs is greater than or equal to rhs.

    A

    and - Native function in topic Conditionals
    Returns true if both expressions are true.
    append - Native function in topic Lists
    Concatenates two lists.
    args - Value in topic Variables
    The command-line arguments passed to the interpreter.

    B

    begins_with - Prelude function in topic Lists
    Tests whether list1 begins with the elements of list2.
    bye - Native function in topic System
    Terminates the process with exit code 0.

    C

    car - Native function in topic Lists
    Returns the first element of a list.
    cdr - Native function in topic Lists
    Returns every element of a list except the first.
    chars - Native function in topic Strings
    Splits a string into a list of single-character strings.
    chdir - Native function in topic System
    Changes the current working directory of the process.
    cons - Native function in topic Lists
    Prepends an element to a list.
    cwd - Native function in topic System
    Returns the current working directory.

    D

    dec - Prelude function in topic Arithmetic
    Returns x decremented by one.
    do - Native function in topic Control Flow
    Evaluates several expressions in order.

    E

    ends_with - Prelude function in topic Lists
    Tests whether list1 ends with the elements of list2.
    exec - Native function in topic System
    Runs a command through the system shell and returns its exit code.
    exit - Native function in topic System
    Terminates the process with the given exit code.

    F

    filter - Prelude function in topic Lists
    Returns the elements for which a predicate returns true.
    foldl - Prelude function in topic Lists
    Reduces a list to a single value, from left to right.
    foreach - Prelude function in topic Lists
    Applies a function to each element for its side effects.
    foreachi - Prelude function in topic Lists
    Like foreach, but the function also receives the index of each element.

    G

    get_env - Native function in topic System
    Returns the value of an environment variable.
    get_env_unit - Native function in topic System
    Returns the value of an environment variable, or unit if it is not set.

    H

    has_prefix - Prelude function in topic Strings
    Tests whether a string begins with another string.
    has_suffix - Prelude function in topic Strings
    Tests whether a string ends with another string.

    I

    if - Native function in topic Control Flow
    Evaluates one of two expressions depending on a condition.
    inc - Prelude function in topic Arithmetic
    Returns x incremented by one.
    include - Native function in topic System
    Evaluates another source file in the current scope.
    isbool - Native function in topic Type Checking
    Tests whether a value is a bool.
    isfun - Native function in topic Type Checking
    Tests whether a value is a function written in Nomad Lisp.
    islist - Native function in topic Type Checking
    Tests whether a value is a list.
    ismac - Native function in topic Type Checking
    Tests whether a value is a macro.
    isnative - Native function in topic Type Checking
    Tests whether a value is a native function.
    isnum - Native function in topic Type Checking
    Tests whether a value is a number.
    isrecord - Native function in topic Type Checking
    Tests whether a value is a record.
    isstr - Native function in topic Type Checking
    Tests whether a value is a string.
    isunit - Native function in topic Type Checking
    Tests whether a value is unit.

    L

    lambda - Native function in topic Functions
    Creates an anonymous function.
    len - Prelude function in topic Lists
    Returns the number of elements in a list.
    let - Native function in topic Variables
    Binds the value of an expression to a name in the current scope.
    letfun - Native function in topic Functions
    Defines a named function in the current scope.
    letmac - Native function in topic Macros
    Defines a macro in the current scope.
    list - Native function in topic Lists
    Evaluates the given expressions and returns them as a list.
    list_init - Prelude function in topic Lists
    Creates a list of n elements by applying a function to each index.
    lower - Native function in topic Strings
    Converts the ASCII letters of a string to lowercase.

    M

    map - Prelude function in topic Lists
    Applies a function to each element and returns the list of results.
    mapi - Prelude function in topic Lists
    Like map, but the function also receives the index of each element.
    mkdir - Native function in topic Input/Output
    Creates a directory.
    mod - Native function in topic Arithmetic
    Computes the remainder of dividing lhs by rhs.
    mut - Native function in topic Variables
    Replaces the value of an existing binding.

    N

    not - Prelude function in topic Conditionals
    Negates a boolean.
    nth - Prelude function in topic Lists
    Returns the element at a zero-based index.
    nth_unit - Prelude function in topic Lists
    Returns the element at a zero-based index, or unit if there is none.

    O

    or - Native function in topic Conditionals
    Returns true if either expression is true.

    P

    print - Native function in topic Input/Output
    Prints one or more values to standard output.
    print_env - Native function in topic System
    Prints all bindings of the current scope and every enclosing scope.
    println - Native function in topic Input/Output
    Like print, followed by a newline.

    R

    range - Prelude function in topic Lists
    Returns the elements between two indices, both inclusive.
    read_dir - Native function in topic Input/Output
    Returns the names of the entries in a directory.
    read_file - Native function in topic Input/Output
    Reads the entire contents of a file.
    readln - Native function in topic Input/Output
    Prints a prompt and reads a line from standard input.
    record - Native function in topic Records
    Constructs a record from field-value pairs.
    record_mut - Native function in topic Records
    Replaces the value of an existing record field.
    remove_dir - Native function in topic Input/Output
    Removes an empty directory.
    remove_file - Native function in topic Input/Output
    Deletes a file.
    rev - Prelude function in topic Lists
    Returns a list with the elements in reverse order.

    S

    scoped - Native function in topic Variables
    Evaluates an expression within a new lexical scope.
    splitws - Native function in topic Strings
    Splits a string on spaces, discarding empty parts.
    sprint - Native function in topic Strings
    Converts one or more values to strings and concatenates them.
    string_to_num - Native function in topic Conversions
    Parses a string as a number.
    strlen - Prelude function in topic Strings
    Returns the length of a string in bytes.
    switch - Native function in topic Control Flow
    Selects an arm by comparing a value against several matchers.

    T

    throw - Native function in topic Control Flow
    Throws an exception carrying a message.
    to_string - Native function in topic Conversions
    Converts any value to its string representation.
    trim - Native function in topic Strings
    Removes leading and trailing whitespace from a string.
    try - Native function in topic Control Flow
    Evaluates an expression and recovers from any exception it throws.
    typeof - Prelude function in topic Type Checking
    Returns the name of the type of a value.

    U

    unless - Macro in topic Control Flow
    The inverse of if.

    W

    when - Macro in topic Control Flow
    Evaluates an expression only if a condition holds.
    write_file - Native function in topic Input/Output
    Writes a string to a file, replacing its contents.
