Topic Conditionals

  • Boolean logic, equality and numeric comparison.

    Nomad Lisp has no notion of truthiness. Logical operators and conditional constructs require operands of type bool.

    • Function Detail

      • not

        (not <bool>)

        Negates a boolean.

        Kind:
        Implemented in Nomad Lisp as part of the prelude.
        Returns:
        bool
        Throws:
        EvaluationError - if the argument is not a bool
        Example:
        (not true) # false

      • and

        (and <a> <b>)

        Returns true if both expressions are true.

        Short-circuits: b is not evaluated if a is false.

        Kind:
        Implemented natively by the interpreter.
        Returns:
        bool
        Throws:
        EvaluationError - if an evaluated operand is not a bool

      • or

        (or <a> <b>)

        Returns true if either expression is true.

        Short-circuits: b is not evaluated if a is true.

        Kind:
        Implemented natively by the interpreter.
        Returns:
        bool
        Throws:
        EvaluationError - if an evaluated operand is not a bool

      • =

        (= <x> <y>)

        Tests two values for equality.

        Numbers, strings, bools and unit are compared by value. Lists are equal if they have the same length and their elements are pairwise equal. Functions, native functions, macros and records are only equal to themselves.

        Values of different types are never equal; no exception is thrown.

        Kind:
        Implemented natively by the interpreter.
        Returns:
        bool
        Example:
        (= 1 1) # true
(= (list 1 2) (list 1 2)) # true
(= 1 "1") # false

      • !=

        (!= <x> <y>)

        The inverse of =.

        Expands to (not (= x y)).

        Kind:
        A macro defined in the prelude.
        Returns:
        bool
