Topic Records

  • Mutable collections of named fields.

    Records group several named values into a single value, so that fields can be accessed by name instead of by index. Records are the only values in Nomad Lisp whose contents can change; fields are changed with record_mut.

    • Function Detail

      • record

        (record (<field> <expression>)...)

        Constructs a record from field-value pairs.

        Kind:
        Implemented natively by the interpreter.
        Returns:
        record
        Throws:
        EvaluationError - if a field is not of the form (name expression)
        Example:
        (record
  (name "John Doe")
  (age 21)
  (job "Electrician"))

      • .

        (. <record> <field>)

        Returns the value of a record field.

        Kind:
        Implemented natively by the interpreter.
        Returns:
        the value of the field
        Throws:
        EvaluationError - if the first argument is not a record, or if the field does not exist
        Example:
        (let person
  (record
    (name "John Doe")
    (age 21)))

(println (. person name)) # John Doe
(println (. person age)) # 21

      • record_mut

        (record_mut <record> <field> <expression>)

        Replaces the value of an existing record field.

        Kind:
        Implemented natively by the interpreter.
        Returns:
        unit
        Throws:
        EvaluationError - if the first argument is not a record, or if the field does not exist
        Example:
        (record_mut person age (inc (. person age)))
(println (. person age)) # 22
