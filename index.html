    Nomad Lisp Language and Library Documentation

    This document is the reference for the Nomad Lisp programming language and its standard library. Nomad Lisp is a modern, readable, dynamically typed and interpreted Lisp dialect. The reference interpreter is written in OCaml.

    Processes, environment and the interpreter itself.

    Nomad Lisp programs are composed of S-expressions. Every construct of the language, including if, let and lambda, is a function that receives its arguments unevaluated, which keeps the core of the language exceptionally small.

    The functions documented here fall into three kinds. Native functions are implemented by the interpreter itself. Prelude functions are written in Nomad Lisp and loaded on startup. Macros are syntactic templates defined in the prelude.

    New users should begin with Getting Started and the Language Guide. Those wishing to write their own implementation should consult the Implementer's Reference.
