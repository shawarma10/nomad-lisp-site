    • Function Detail

      • exec

        (exec <command: string>)

        Runs a command through the system shell and returns its exit code.

        On UNIX-like systems the command is run by sh, on Windows by cmd.exe. The command's output is not captured.

        Kind:
        Implemented natively by the interpreter.
        Returns:
        number
        Example:
        (exec "ls -l")

      • exit

        (exit <code: number>)

        Terminates the process with the given exit code.

        Kind:
        Implemented natively by the interpreter.
        Returns:
        never returns

      • bye

        (bye)

        Terminates the process with exit code 0.

        Shorthand for (exit 0); commonly used to leave the REPL.

        Kind:
        Implemented natively by the interpreter.
        Returns:
        never returns

      • cwd

        (cwd)

        Returns the current working directory.

        Kind:
        Implemented natively by the interpreter.
        Returns:
        string

      • chdir

        (chdir <path: string>)

        Changes the current working directory of the process.

        Kind:
        Implemented natively by the interpreter.
        Returns:
        unit
        Throws:
        EvaluationError - if the path does not exist

      • get_env

        (get_env <variable: string>)

        Returns the value of an environment variable.

        Kind:
        Implemented natively by the interpreter.
        Returns:
        string
        Throws:
        EvaluationError - if the variable is not set

      • get_env_unit

        (get_env_unit <variable: string>)

        Returns the value of an environment variable, or unit if it is not set.

        Kind:
        Implemented natively by the interpreter.
        Returns:
        string | unit

      • include

        (include <path>)

        Evaluates another source file in the current scope.

        The path is written as a bare symbol, not as a string. All bindings made by the included file become visible to the includer.

        Kind:
        Implemented natively by the interpreter.
        Returns:
        unit
        Throws:
        EvaluationError - if the file cannot be read, or if evaluating it throws
        Example:
        (include lib/helpers.nomad)

      • print_env

        (print_env)

        Prints all bindings of the current scope and every enclosing scope.

        Intended for debugging.

        Kind:
        Implemented natively by the interpreter.
        Returns:
        unit
