Topic Conversions

  • Converting values between types.

    Nomad Lisp never converts values implicitly. These functions convert explicitly between strings and other types.

    • Function Summary

    • Function Detail

      • to_string

        (to_string <expression>)

        Converts any value to its string representation.

        Numbers without a fractional part are rendered as integers; other numbers are rendered with two decimal places.

        Kind:
        Implemented natively by the interpreter.
        Returns:
        string
        Example:
        (to_string 123) # "123"
(to_string (list 1 2 3)) # "(1 2 3)"
(to_string (lambda (x) x)) # "<FUNCTION>"
(to_string if) # "<NATIVEFUNCTION>"

      • string_to_num

        (string_to_num <string>)

        Parses a string as a number.

        Kind:
        Implemented natively by the interpreter.
        Returns:
        number
        Throws:
        EvaluationError - if the argument is not a string, or if it cannot be parsed
        Example:
        (string_to_num "42") # 42
