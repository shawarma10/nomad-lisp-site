Topic Arithmetic

  • Arithmetic on numbers, with limited support for strings.

    All numbers in Nomad Lisp are 64-bit floating point numbers. Numbers without a fractional part are printed as integers. All arithmetic functions take exactly two operands.

    • Function Detail

      • +

        (+ <lhs> <rhs>)

        Adds two numbers or concatenates two strings.

        Kind:
        Implemented natively by the interpreter.
        Returns:
        number | string
        Throws:
        EvaluationError - if the operands are not both numbers or both strings
        Example:
        (+ 1 2) # 3
(+ "Hello, " "World") # "Hello, World"

      • -

        (- <lhs> <rhs>)

        Subtracts rhs from lhs.

        Kind:
        Implemented natively by the interpreter.
        Returns:
        number
        Throws:
        EvaluationError - if either operand is not a number

      • *

        (* <lhs> <rhs>)

        Multiplies two numbers, or repeats a string.

        If one operand is a string and the other a number, the string is repeated that many times. The number is truncated to an integer; values below 1 yield the empty string.

        Kind:
        Implemented natively by the interpreter.
        Returns:
        number | string
        Throws:
        EvaluationError - if the operands are of any other combination of types
        Example:
        (* 9 9) # 81
(* 2 "Hello ") # "Hello Hello "
(* "Hello " 2) # "Hello Hello "

      • /

        (/ <lhs> <rhs>)

        Divides lhs by rhs.

        Kind:
        Implemented natively by the interpreter.
        Returns:
        number
        Throws:
        EvaluationError - if either operand is not a number, or if rhs is 0

      • mod

        (mod <lhs> <rhs>)

        Computes the remainder of dividing lhs by rhs.

        The result has the same sign as lhs.

        Kind:
        Implemented natively by the interpreter.
        Returns:
        number
        Throws:
        EvaluationError - if either operand is not a number
        Example:
        (mod 10 3) # 1

      • inc

        (inc <x>)

        Returns x incremented by one.

        Kind:
        Implemented in Nomad Lisp as part of the prelude.
        Returns:
        number
        Throws:
        EvaluationError - if x is not a number

      • dec

        (dec <x>)

        Returns x decremented by one.

        Kind:
        Implemented in Nomad Lisp as part of the prelude.
        Returns:
        number
        Throws:
        EvaluationError - if x is not a number
