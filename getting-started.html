    Guide

    Getting Started

    Building the interpreter and running programs.

    Prerequisites

    Building Nomad Lisp requires git, opam and the dune build system.

    Building from source

    git clone https://github.com/shawarma10/nomad-lisp
cd nomad-lisp
opam install .
eval $(opam env)
dune build
cp _build/default/bin/main.exe nomad

    Command-line usage

    The nomad executable supports the following modes of operation:

    • nomad or nomad --repl (-r) starts the interactive REPL.
    • nomad <file> [args...] runs a source file as a script. Further arguments are available through args.
    • nomad --eval <expression> (-e) evaluates an expression and prints its value.
    • nomad --help (-h) prints usage information.

    The REPL

    In the REPL, every input is evaluated and its value is printed. Try some basic arithmetic:

    (+ 1 2)
(* 6 7)
(+ (* 10 5) (- 1000 250))

    Or this tiny program that greets you:

    (println (+ "Hello, " (readln "Enter your name: ")))

    To leave the REPL, evaluate (bye) or press Ctrl-D.

    Scripts

    Scripts conventionally use the .nomad file extension. On UNIX-like systems, a script can be made directly executable with a shebang line, since # begins a comment:

    #!/usr/bin/env nomad
(println "Hello from a script!")
