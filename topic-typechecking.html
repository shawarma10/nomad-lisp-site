Topic Type Checking

  • Inspecting the type of a value at runtime.

    Nomad Lisp is dynamically typed. Its types are string, number, bool, list, record, function, native (native function), macro and unit.

    All is predicates return false, rather than throwing, if evaluating their argument fails.

      • typeof

        (typeof <expression>)

        Returns the name of the type of a value.

        One of "string", "number", "bool", "list", "record", "function", "native", "unit" or "macro". "unknown" should never be returned; if it is, please report an issue.

        Kind:
        Implemented in Nomad Lisp as part of the prelude.
        Returns:
        string
        Example:
        (typeof "Hello") # "string"
(typeof 21) # "number"
(typeof (list 1 2 3 4)) # "list"
(typeof (lambda (x) x)) # "function"
